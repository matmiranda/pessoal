# 📌 Plano de Desenvolvimento Individual (PDI)

## 🎯 Curto Prazo (0–6 meses)
- Concluir a pós-graduação em **Arquitetura de Sistemas (FIAP)**.
- Corrida meia maratona - 21k

## 🎯 Médio Prazo (6–18 meses)
- Obter a certificação AWS Practitioner e Developer

## 🎯 Longo Prazo (18–36 meses)
- Maratona - 42km
- Atuar como **Analista de Sistemas Sênior**.  
- Liderar análises funcionais e técnicas em projetos críticos, incluindo:  
  - Mapeamento de riscos.  
  - Análise de impacto técnico.  
  - Proposição de soluções arquiteturais.  
- Participar ativamente do **desenho de arquiteturas** e **decisões estratégicas**.
